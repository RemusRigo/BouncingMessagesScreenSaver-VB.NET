# Bouncing Messages ScreenSaver
Bouncing Messages ScreenSaver: messages that bounce off the edges of your screens



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Messages (a title and a description) bounce around the screen, changing color at every bounce
* A new message every 4 bounces
* Messages are read from JSON files (keyboard shortcuts for Windows, Word, Excel and browsers included)
* Use a random message file, or pick one in Settings
* Multi-Monitor support (bounces off the outer edges, including monitors of different sizes)
* Preview in the Windows **Screen Saver Settings** dialog
* Key: Space: pause/resume the movement
